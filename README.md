# Charurooba M - Developer Portfolio

A responsive, high-performance, cyber/dark-themed portfolio website for **Charurooba M (Aspiring Web Developer)**.

## Features
- **Modern Cyber Aesthetic**: Sleek dark theme (`#030508`), neon cyan (`#00d5dd`) & violet accents (`#a66cff`), Space Mono & Inter typography.
- **Glassmorphic Navigation**: Sticky header with active scroll highlighting and animated mobile hamburger toggle.
- **Hero Section**: Live collaboration badge, role overview, dynamic typography, framed profile card with code preview and location tag.
- **Categorized Skills**: Programming, Databases & Tools, UI/UX & Web Design, Complementary Knowledge, and Professional Soft Skills.
- **Featured Projects**: Uber Management System (Flask/MySQL CRUD), Gym Membership Tracker, and SIET Tumakuru Hackathon.
- **Academic & Industry Training**: Novitech R&D 30-Day Masterclass (Full-Stack & UI/UX) and college symposium paper presentation.
- **Education Timeline**: B.Tech in Information Technology (2023–2027), Higher Secondary (HSC), and SSLC.
- **Interactive Contact Form**: Client-side validation, instant feedback, and seamless `mailto:` integration.
- **Responsive Design**: Full mobile and tablet support from 360px up to 4K displays.

## How to Run Locally
1. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
2. Or run a lightweight local web server:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000` in your browser.
